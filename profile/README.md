# W3C Open Source Program Repositories

W3C operates this GitHub organization to host open source projects that are part of the [W3C Open Source Program](https://github.com/w3c-oss/open-source-program).

In order to make changes to this organization (including adding repos), please coordinate with @ianbjacobs and @tidoust.

# Backups

Repos in this organization are [backed up by W3C](https://www.w3.org/guide/github/backup.html).
